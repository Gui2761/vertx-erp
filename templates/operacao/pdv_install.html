Instalar VERTYX PDVAplicativo com entrada direta no PDV. Login e permissões continuam obrigatórios.
Como instalar no computador ou celular

No Chrome: menu ⋮ → Transmitir, salvar e compartilhar → Instalar página como app. No Edge: menu ⋯ → Aplicativos → Instalar este site como aplicativo. A opção pode variar com a versão do navegador.

No iPhone: Safari → Compartilhar → Adicionar à Tela de Início. Instale a partir desta tela do PDV.

O botão aparece quando o navegador disponibiliza a instalação. Se já instalou, abra pelo ícone. Use HTTPS (ou localhost no teste local), uma janela normal e confira as políticas do navegador.

Operações offline ficam pendentes no dispositivo após preparação de seu caixa. Na reconexão, o servidor revalida os dados antes de confirmar. Não há emissão fiscal offline.
